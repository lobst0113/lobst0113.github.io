LOBST案件管理　制定日：2026年10月28日

LOBST案件管理（以下「本アプリ」）は、構造計算事務所 LOBST が社内で使用する Windows デスクトップアプリです。本ポリシーは、本アプリが Google アカウントのデータをどのように扱うかを説明します。

1. 取得する情報

利用者が許可した場合に限り、Google カレンダー API を通じて次の情報にアクセスします。

  • 登録しているカレンダーの一覧（名前・色・権限）
  • カレンダーの予定（タイトル・日時・場所・説明・色）

2. 利用目的

取得した情報は、本アプリの画面にスケジュールを表示し、利用者の操作に応じて予定を作成・変更・削除するためだけに使用します。広告、分析、その他の目的には使用しません。

3. 保存と送信

  • カレンダーのデータは、本アプリと Google の間でのみやり取りされます。開発者を含む第三者のサーバーには送信しません。
  • Google への接続に使う認証情報は、利用者の PC 内に Windows の暗号化機能で暗号化して保存します。Google アカウントのパスワードは保存しません。

4. 第三者への提供

取得した情報を第三者に販売・提供・共有することはありません。

5. Google API サービスのユーザーデータに関するポリシーの遵守

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

LOBST案件管理's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. アクセスの取り消し

本アプリの設定画面の「接続を解除」、または Google アカウントの「サードパーティ製のアプリとサービス」から、いつでもアクセス許可を取り消せます。

7. お問い合わせ

本ポリシーに関するお問い合わせは lobst0113@gmail.com までご連絡ください。
